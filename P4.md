# P4: GitHub README and version tags

## Aim
To create a README file, commit it, and add a version tag.

## Create a README file

```bash
touch README.md
```

Add the following content to `README.md`:

```markdown
# My Portfolio

This is my personal portfolio website.

## About
I am a student learning web development.

## Skills
- HTML
- CSS
- Git
- GitHub

## Projects
My practice projects will be listed here.
```

## Git commands

```bash
# Stage and commit the README
git add README.md
git commit -m "Add project README"

# Create a version tag
git tag -a v1.0 -m "First version"

# Display tags
git tag

# Display details of the tag
git show v1.0
```

## Push commits and tag to GitHub

```bash
git push origin main
git push origin v1.0
```

## Expected result
- GitHub displays the README on the repository home page.
- The local repository contains a tag named `v1.0`.
- After pushing, the tag is also available on GitHub.

## Explanation
A README explains what a project does and how to use it. A Git tag marks a particular version of the project.

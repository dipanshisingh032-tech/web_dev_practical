# P2: Portfolio repo with an initial commit

## Aim
To create a portfolio project, initialise Git, and make the first commit.

## Commands

```bash
# Create and enter the project folder
mkdir my-portfolio
cd my-portfolio

# Create a basic web page
touch index.html

# Start a Git repository
git init

# Set your Git identity (only needed if not already configured)
git config user.name "Your Name"
git config user.email "your-email@example.com"

# Check the repository status
git status

# Add the file to the staging area
git add index.html

# Create the first commit
git commit -m "Initial portfolio commit"

# View the commit
git log --oneline
```

## Expected result
Git creates a repository and records the first commit. The `git log --oneline` command displays a short commit ID followed by:

```text
Initial portfolio commit
```

## Explanation
- `git init` starts a Git repository.
- `git status` shows changed and staged files.
- `git add` stages a file for committing.
- `git commit` saves a snapshot of the staged files.
- `git log --oneline` displays a short commit history.

## Optional: connect to GitHub
Create an empty repository on GitHub, then use its URL:

```bash
git branch -M main
git remote add origin https://github.com/your-username/my-portfolio.git
git push -u origin main
```

Replace the sample username and repository name with your own.

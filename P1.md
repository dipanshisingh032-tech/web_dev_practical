# P1: Project folder and terminal navigation

## Aim
To create a project folder and learn basic terminal navigation commands.

## Commands

```bash
# Show the current folder
pwd

# List files and folders
ls

# Create a new project folder
mkdir my-portfolio

# Move into the project folder
cd my-portfolio

# Create a file
touch index.html

# List files again
ls

# Move one folder back
cd ..

# Check the current location
pwd
```

## Expected result
- `mkdir my-portfolio` creates a folder named `my-portfolio`.
- `cd my-portfolio` enters that folder.
- `touch index.html` creates an empty file.
- `ls` displays `index.html` when run inside the project folder.

## Explanation
- `pwd` shows the current directory.
- `ls` lists the contents of a directory.
- `mkdir` creates a directory.
- `cd` changes the current directory.
- `touch` creates an empty file.
- `cd ..` moves to the parent directory.

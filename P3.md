# P3: Feature-branch Git workflow

## Aim
To create a feature branch, make a change, commit it, and merge it into `main`.

## Commands

```bash
# Check the current branch
git branch

# Create and switch to a feature branch
git switch -c feature/about-section

# Create a file for the new feature
touch about.html

# Stage and commit the change
git add about.html
git commit -m "Add about section"

# Switch back to the main branch
git switch main

# Merge the feature branch into main
git merge feature/about-section

# View the commit history
git log --oneline --all
```

## Expected result
The `feature/about-section` branch is created. The commit made on that branch is merged into `main`.

## Explanation
- A branch lets us work on a feature separately.
- `git switch -c` creates a branch and switches to it.
- `git switch main` returns to the main branch.
- `git merge` combines the branch changes into the current branch.

## Optional: push both branches to GitHub

```bash
git push -u origin main
git push -u origin feature/about-section
```

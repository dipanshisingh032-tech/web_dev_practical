# Web Development Practicals (P1–P13)

Beginner-friendly practical files for Terminal, Git, GitHub, HTML, CSS, Flexbox and Grid.

## Folder contents
- `P1.md` to `P4.md`: terminal and Git/GitHub practicals with commands and expected results.
- `P5.html` to `P13.html`: HTML/CSS practicals. Open each file in a web browser to see its output.

## How to run the HTML practicals
1. Extract this ZIP file.
2. Open the folder.
3. Double-click any `P5.html`–`P13.html` file, or right-click and choose a browser.
4. Edit the file in a text editor and refresh the browser to see changes.

## Note
The Git commands are examples. Replace `your-username` and `your-email@example.com` with your own GitHub details before using them. These files have not been pushed to GitHub.
